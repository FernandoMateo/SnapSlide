## Development

```bash
npm install
npm run dev          # http://localhost:3000
npm run typecheck    # tsc --noEmit
npm run build        # build de producción (también corre TypeScript)
```

No hay tests automatizados todavía. Verifica visualmente: `/` (intro + landing), `/login`, `/dashboard/*` con un Owner y con un Vendedor.

Accesos demo: `avril@snapslide.com` / `snap2026` (Owner) · `daniela@snapslide.com` / `ventas2026` (Vendedor).
